# Skills GD (Geração Digital)

Skills próprias do Nilton, criadas a partir dos apps (Pixel.Afilic, Zap.Afilic, Afilic, Kit Gospel). Todas começam
com **`gd-`**: assim ficam juntas na lista e dá para saber na hora que são nossas. Para usar num projeto:
"vamos desenvolver usando as skills GD".

| Skill | Para quê |
|---|---|
| `gd-layout-apps` | Visual e casca dos apps: menu, administrativo, componentes, cores, celular, app instalável |
| `gd-acesso-membros` | Administrativo: membros, grupos (planos), produtos da Hotmart/Kiwify, webhook de acesso, notificações |
| `gd-pixel-meta` | Pixel do Facebook e rastreio: script da página, CAPI, parâmetro de URL, xcod/src/sck, teste do pixel |
| `gd-vendas-infoproduto` | Ler os avisos de venda (Hotmart, Kiwify, Greenn), Pix × boleto, reembolso, order bump, envio à Meta |
| `gd-pagina-vendas` | Página de vendas: método (motor do @gabrielpdigital), dobras, mockups pelo Codex, bônus, preço, conferência e publicação na Hostinger |
| `gd-publicar-app-meta` | Publicar app na Meta para outras pessoas: Ao vivo, Análise do app (vídeo e usuário de teste), verificações, páginas legais, webhooks, vistoria antes de vender |

Skill nova: crie a pasta `gd-<nome>` aqui em `.claude/skills` e use `name: gd-<nome>` no SKILL.md.
Quando for para o GitHub: repositório **privado**.
